# 腾讯会议课程自动播放 Web 系统（本地版）

## 适用场景

- Windows 10/11，本机持续开机；腾讯会议每天人工进入会议与开始共享。
- 一次排好4天课程，每天上午与下午，每个场次由多个视频按顺序组成。
- 在时段内依据**真实系统日期与时间**自动播放，到下一视频会无缝顺序切换（视频装载仍可能有极短停顿）。不在时段内显示醒目的 **“直播暂停”**。
- 不需要OBS、VLC、云服务器和额外Python第三方包。
- 支持误刷新、错过开播时间后按课程时间恢复至应播视频/位置（需要视频时长有效、浏览器能解码）。

## 从零开始（只需一次）

1. Windows安装 Python 3.10+（建议3.11~3.13），安装时勾选 **Add Python to PATH**。电脑上已安装Microsoft Edge即可。
2. 解压整个压缩包，尽量放在本地磁盘目录如 `D:\TencentTrainingWeb`，不要在压缩包里直接运行。
3. 双击 **`01_启动服务.bat`**，让这个黑色命令行窗口持续保持打开。第一次会自动打开管理后台。
4. 管理后台地址：`http://127.0.0.1:8765/admin`。
5. 设置开始日期、上午开始/结束、下午开始/结束时间，点击 **生成课程表**。默认生成连续4天8个场次。已有场次不会被覆盖；可单独编辑时间或删除。
6. 建议将视频文件按下面目录整理，并在后台“本机文件夹路径”填写根目录、点击 **扫描并导入文件夹**，再点击 **按Day01/AM目录自动排课**。也可以直接把视频拖到上传区，然后手工加入场次。
7. 每个半天检查视频顺序、总时长、未知时长数量。如果出现“未识别时长”，先点击 **浏览器识别未知时长**；不成功可编辑视频手工填写秒数。**不识别时长不能保证准点恢复或连续播控。**
8. 双击 **`02_打开播放端_自动有声播放.bat`**。会启动 Edge/Chrome 独立播放窗口，保留不最小化。这个命令给**独立专用浏览器配置**设置自动有声播放，避免普通浏览器自动播放策略阻断。如果不用脚本而直接打开网址，需要人工点击右上角“启用声音”，并测试到点播放。
9. 在腾讯会议每天人工进入会议 → **共享屏幕** → 选择该独立播放窗口 → 勾选**同时共享电脑声音**、**视频流畅度优先**，使用第二台设备以学员身份验证有声画面。
10. 每天结束后人工结束腾讯会议，但不关闭本地服务、不关闭播放窗口、不让电脑睡眠。第二天只需重新进入腾讯会议并共享窗口。

## 视频目录建议

```text
D:\TrainingLive\
  Day01\
    AM\
      01_课程简介.mp4
      02_人工智能基础.mp4
    PM\
      01_下午案例.mp4
  Day02\
    AM\...
    PM\...
  Day03\
    AM\...
    PM\...
  Day04\
    AM\...
    PM\...
```

视频名用 `01_...` `02_...` 前缀便于顺序正确；自动排课按**日期先后对应 Day01~Day04**，支持更多天。非该目录结构也能手动添加/排序。

## 自动播放逻辑

- 时段外（早上开课前、午休、晚上、培训日期之外）：画面中央显示 **直播暂停**。
- 时段内：根据【场次开始时间】和【前面所有视频的时长】定位当前视频和准确进度；这样网页刷新后也能定位到该时刻该播的内容。
- 时段视频不足规定时长：提前播完显示“课程已播放完毕”，不会循环播放，也**不能将剩余空档计入有效教学时长**。
- 时段视频超过规定时长：到结束时间自动切换“直播暂停”，后面的部分会被截断。
- 文件丢失、格式不支持或时长不明：显示异常，后台可查看日志。
- 由于播放器根据时钟计算位置，电脑未保持准确校时、文件时长错误、卡顿缓冲或转码异常会影响播放；正式开播前请做联调。

## 腾讯会议区别

这套方案是**让腾讯会议共享浏览器窗口**。不是自动控制腾讯会议开会或官方“直播”按钮。学员可通过腾讯会议入会观看；若需要腾讯会议的官方直播链接，则还要在会议内按当前账号权限人工开始官方直播。

请使用**支持足够人数和会议持续时长的账号**，不要误用单场40分钟限制的免费多人会议；确认实际收费版本权益。

## 系统安全与备份

- 服务默认只监听 `127.0.0.1:8765`，没有对外开放与账号登录功能；**不要把端口映射至公网或设成 `0.0.0.0` 对外开放**。
- 数据库位于 `data\training.sqlite3`，上传副本位于 `data\uploads`，原始文件夹导入只存路径引用、不会修改原视频。
- 移除视频库记录不会删除磁盘文件；删除课程场次不会删除视频。
- 服务关闭，或者专用播放器窗口关闭后，**就不会继续自动播**；不要只开服务而忘记打开播放窗口。
- 备用电脑/备用网络、人工抽检、上课签到与其他培训管理要求需要另外安排。
- **播放记录不是培训出勤、交互及学时认定证明。** 录播是否可以用于特定培训，请以项目适用规定为准。

## 常见故障

- **一键启动没反应**：确认 `python --version` 可执行且版本≥3.10，路径不要含不常见特殊字符，关闭被占用的8765端口。
- **有画面无声音**：腾讯会议共享时勾选“同时共享电脑声音”，Windows音量不能为0；第二台设备验证。
- **到点不自动播放**：浏览器自动播放权限，优先用 `02_打开播放端_自动有声播放.bat`；浏览器页面第一次打开也可以点击右上角“启用声音”。
- **画面黑屏**：腾讯会议不要共享已经最小化的浏览器窗口；更改为共享独立显示器亦可。
- **某个视频播不了**：浏览器对MOV/MKV和某些HEVC视频支持有限；建议改为MP4(H.264/AAC)。
- **一段视频后卡住**：先看后台日志、重新验证视频时长，确认视频格式可播放，再模拟连续播放。
- **播放器数据更新延迟**：计划默认每15秒同步一次，播放页右上角可手动点“同步计划”。正式培训中不建议修改已开始的场次。
- **电脑掉电、休眠、浏览器最小化**：不支持无人值守的绝对不中断保障；需人工发现与恢复。

## 额外说明

专用启动脚本使用浏览器启动参数 `--autoplay-policy=no-user-gesture-required`，仅在独立的本机播课浏览器配置中生效。浏览器未来版本可能更改相关支持；正式活动开始前应使用实际机器、实际腾讯会议账号完整测试。
